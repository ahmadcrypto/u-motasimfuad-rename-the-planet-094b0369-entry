One funny new name for a planet, plus the why, in a single line: Jupiter's 300-year-old Great Red Spot storm, renamed as a grudge it refuses to drop.

> Rename Jupiter 'The Grudge' — its Great Red Spot storm has raged for 300 years and still won't forgive anyone.

`main.ts` (Node 22, no dependencies) writes the line to `/output/entry.txt`, validating it is 1–200 characters, not whitespace-only, and with no trailing newline.
